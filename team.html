About FakeWS

FakeWS is an open source project created by Antimatter Studios to make local AWS development easier and more accessible.

Why We Built This

Testing against real AWS services is slow, expensive, and requires internet connectivity. FakeWS gives you a complete local AWS environment that starts in seconds, costs nothing, and works offline.

Open Source

FakeWS is built on top of excellent open source projects like MinIO, ElasticMQ, Moto, and more. We package them together with a unified configuration and an inspector console.
